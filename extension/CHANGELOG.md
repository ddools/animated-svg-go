# Changelog

## 0.1.0

First release.

- Open any `.svg` with **Open with Animated SVG GO**, from the explorer, the editor title bar or the command palette.
- Nine effects: Spin, Fade, Draw, Pop, Float, Wiggle, Pulse, Slide in and Colour shift. Stagger, easings, pivots and a timeline.
- Export an animated SVG, an SVG + CSS snippet, an SVG + JS snippet, a GIF or an MP4, saved where you choose.
- Your effects are kept per file and come back when you reopen it. A changed file starts fresh.
- Follows your VS Code theme, light or dark.
- Your SVG is never changed, and nothing leaves your machine.
